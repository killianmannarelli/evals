# Meta-Analysis Plan: 100 Psychology Replication Studies (2015-2025)

## Overview

This project conducts a meta-analysis of 100 published replication attempts in psychology drawn from the 2015-2025 period. The replications were selected from the Reproducibility Project: Psychology (Open Science Collaboration, 2015), Many Labs 1-5, the Social Sciences Replication Project (Camerer et al., 2018), and individual high-profile registered replications published in *Psychological Science*, *PNAS*, *Nature Human Behaviour*, *JPSP*, and elsewhere.

## Final output structure

- `plan.md` (this file) -- assignment table and schema
- `result_001.md` ... `result_100.md` -- per-paper structured summaries
- `meta_analysis_data.csv` -- consolidated structured data
- `forest_plot.png` -- visualised effect sizes
- `bias_table.md` -- risk-of-bias distribution
- `final_report.md` -- assembled meta-analytic report

## Output Schema

Each `result_{NNN}.md` must follow this exact structure:

```yaml
---
STATUS: complete
original_effect_size: <Cohen's d>
original_sample_size: <N>
replication_effect_size: <Cohen's d>
replication_sample_size: <N>
outcome: successful_replication | failed_replication
risk_of_bias_score: <1-5>
full_citation_apa7: "<APA-7 citation>"
---

## Summary of <Paper Title>

### Original Study Method
...

### Replication Study Method
...

### Outcome Analysis
...
```

## Quality Criteria

- `STATUS: complete` requires all YAML fields filled and a summary >= 500 words.
- `STATUS: partial` is allowed if a data point is genuinely not reported in the literature.
- Risk-of-bias scoring follows a 1-5 ordinal scale based on Cochrane ROB-style criteria (selection, performance, detection, attrition, reporting).
